#Practising all the git commands:

git --version
git clone <URL>
modify any file inside the repository
git add <file name that need to be staged for next commit>
git commit -m <File name need to be included for in the commit>
git push -- push the changes to github repository

After commiting need to push to github:

git push
it will ask for username and password --> if authentication fails we need to get Personal access token to connect to remote repository

-- github token setting
-- give required details
-- generate the PAT(Personal access token)
-- now with that token we can perform git push

#Now in github repository we can see the modified changes clearly

git status -- to view the status of what are the files that got modified and which is unstaged  -- if staged it will show in green color in terminal

git diff -- this will show which line was changed or edited or added in the particular file -- with that u can stage that and commit the latest process

git log --oneline -- gives the logs in compact form
